# Pilotys property-manager narrative v2

Migrates the owner Journal and SMS briefings from raw decisions to structured
situations.

- The pricing engine is unchanged.
- The raw `ops_decisions` audit trail is preserved.
- Journal cards use natural sentences and first-person manager language.
- Technical evidence is hidden under “Voir pourquoi”.
- Briefings contain at most a few short stories rather than telemetry bullets.
- Situation building runs before every scheduled briefing.
