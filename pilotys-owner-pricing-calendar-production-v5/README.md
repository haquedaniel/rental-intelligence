# Pilotys owner pricing calendar production v5

Focused layout correction on top of v4.

## Changes

- Reservation bars now use a fixed lane directly below the day number.
- Available-night prices use a separate middle lane.
- Market tension remains visible at the bottom of every priced date, including occupied nights.
- Prices remain hidden for occupied nights only.
- Checkout-day prices remain visible because the checkout night is available.
- Season dots remain beside the date.
- The row height is slightly reduced from v4 while preserving clear separation between all three layers.

No database migration is required.
