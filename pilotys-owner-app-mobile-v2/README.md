# Pilotys Owner App — Mobile UX v2

Implements the agreed mobile owner-app pass:

- Dashboard: reservation/planning calendar removed; compact occupancy table restored.
- Operations: an outstanding payment appears first only when present; cleaning planning follows; routine arrivals/departures no longer appear in important actions; planning legend removed.
- Pricing: opens directly on the calendar with the property name; property controls and strategy action move below.
- Navigation: flatter bottom bar, flush to the safe-area bottom; `Compte` replaces `Réglages`.
- Header: new Pilotys logo plus `Espace propriétaire` in the cockpit and shared owner header.

No database writes or migrations are included.
